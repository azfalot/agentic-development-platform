# Security policy

Do not file credentials, tokens, private paths, process logs, or sensitive task evidence in a public issue. Report a vulnerability privately to the repository owner through GitHub's security-advisory flow when available. Until a supported disclosure channel is configured, open a minimal issue containing no exploit details and ask for a private contact.

Treat contracts and repository content as untrusted input. Keep real execution budgets at zero by default, scope writes narrowly, and review evidence before merge.
